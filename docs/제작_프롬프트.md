# 📋 교실 자리배치 웹앱 제작 프롬프트

아래 내용을 그대로 AI(Claude, ChatGPT 등)에 붙여넣으면 동일한 웹앱을 만들 수 있습니다.

---

## 프롬프트

바닐라 HTML/CSS/JavaScript(프레임워크·라이브러리 없음)로 "교실 자리배치" 웹앱을 만들어줘.
파일은 index.html, style.css, script.js 세 개로 분리하고, 모바일에서도 잘 보이게 반응형으로 만들어줘.

### 목적
선생님이 학생들의 자리를 랜덤으로 배치해주는 도구. 특히 같은 성별(남학생끼리, 여학생끼리)이
서로 옆·앞뒤로 붙지 않도록 자동 배치하는 것이 핵심 기능이야.

### 화면 구성
1. **상단 바**
   - 가운데 제목: "🪑 교실 자리배치"
   - 우측 상단: 한글/영어 전환 토글 버튼 ("🌐 EN" ↔ "🌐 한글")

2. **컨트롤 패널 (흰색 카드)**
   - 가로(분단/열) 숫자 입력 (1~12, 기본 5)
   - 세로(줄) 숫자 입력 (1~12, 기본 4)
   - "자리 설정" 버튼 → 입력한 가로×세로 크기로 책상 격자를 새로 생성
   - 남학생 명단 영역: "👦 남학생 명단 (한 줄에 한 명)" 라벨 + 인원수 숫자 입력(명) + 여러 줄 textarea
   - 여학생 명단 영역: "👧 여학생 명단 (한 줄에 한 명)" 라벨 + 인원수 숫자 입력(명) + 여러 줄 textarea
   - "🎲 랜덤 배치" 버튼, "초기화" 버튼

3. **안내/경고 영역**
   - 경고 메시지 표시줄 (빨간색)
   - 사용법 힌트 문구
   - 성별 범례: 파란 점=남학생, 분홍 점=여학생

4. **교실 (흰색 카드)**
   - 상단: "칠판" (초록 칠판 + 갈색 나무 테두리 느낌)
   - 왼쪽 벽: "🖥️ 선생님 책상" (주황색)
   - 가운데: 학생 책상 격자 (CSS grid)
   - 오른쪽 벽: "🚪 앞문", "🚪 뒷문" (나무문 + 손잡이 느낌, 위아래로 배치)
   - 하단: 상태 표시줄 (전체/사용/빈자리 개수, 배치 후엔 배치 인원)

### 책상(desk) 동작
- 각 책상은 CSS로 그린 "책상 상판 + 의자" 모양. 좌측 상단에 번호 표시.
- 책상을 클릭하면 "사용(active)" ↔ "빈자리(disabled)" 토글. 빈자리는 점선 처리하고 배치 대상에서 제외.
- 상태: 빈 책상(active), 학생 배정됨(filled), 사용 안 함(disabled).
- 남학생 배정 책상은 파란 계열, 여학생은 분홍 계열로 색상 구분.

### 랜덤 배치 로직 (가장 중요)
- 명단이 입력돼 있으면 명단의 이름을 사용, 비어 있으면 인원수만큼 자동 이름 생성
  (한글: 남1, 남2… / 여1, 여2… , 영어: B1, B2… / G1, G2…)
- **남·여 둘 다 있을 때: 같은 성별이 상하좌우로 인접하지 않도록 분리 배치**
  1. **체스판(격자 2색칠) 방식 우선**: (row+col)이 짝수인 칸과 홀수인 칸으로 나누고,
     한 성별을 한 색 칸에만 배치하면 인접 위반이 0이 됨. 가능한 배치 방향은 랜덤 선택.
  2. **인원 비율상 체스판이 불가능하면**: 무작위 초기 배치를 여러 번(약 25회) 재시작하면서,
     서로 다른 성별 자리끼리 교환(swap)하는 지역 탐색으로 "같은 성별 인접 쌍 수"를 최소화.
     인접 쌍은 오른쪽·아래 이웃만 검사해서 중복 계산 방지.
  3. 완벽 분리가 불가능하면 "같은 성별 N쌍이 이웃했어요" 경고 표시.
- **한 성별만 있을 때**: 단순 무작위 배치(색상은 유지).
- 배치 순서(이름·자리)는 Fisher-Yates 셔플로 무작위화.
- 배치 시 책상이 순차적으로 뒤집히며(flipIn: rotateY) 나타나는 애니메이션, 딜레이는 랜덤.

### 유효성 검사 / 경고
- 학생 1명 미만: "학생 수는 1명 이상이어야 합니다."
- 51명 이상: "최대 50명까지 입력할 수 있습니다."
- 사용 책상 0개: "사용할 책상을 최소 1개 이상 선택하세요."
- 학생 수 > 사용 책상 수: "선택된 책상(N개)보다 학생(M명)이 많습니다. 책상을 더 선택하세요."
- 명단 입력 시엔 인원수 입력값보다 명단 개수를 우선 사용.

### 초기화 버튼
- 격자 크기와 책상 사용/빈자리 선택 상태는 유지한 채, 배치 결과만 리셋.

### 다국어(i18n)
- 모든 UI 텍스트를 한국어/영어 두 세트로 관리(객체로 관리).
- HTML 요소에 `data-i18n` 속성을 달아 언어 전환 시 텍스트/placeholder를 일괄 교체.
- 언어 전환 시 현재 화면 상태(배치 결과, 경고)도 새 언어로 다시 렌더링.
- 자동 이름 접두사도 언어에 맞게(남/여 ↔ B/G).

### 디자인
- 연한 연두색 그라데이션 배경, 흰색 라운드 카드, 부드러운 그림자.
- 남학생=파랑(#7aa7f0 계열), 여학생=분홍(#f3a2c4 계열).
- 버튼: 자리설정=연두, 랜덤배치=파랑, 초기화=분홍.
- 반응형: 720px/600px 브레이크포인트에서 벽 요소를 좁히고, 좁은 화면에선 문 라벨 숨김.
- 폰트: "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR" 계열.
- XSS 방지를 위해 이름 출력 시 HTML escape 처리.
