## 3. 앱 파일(.aab) 만들기 — PWABuilder

1. 앱을 배포해서 `https://seating-brown.vercel.app`가 열리는지 확인합니다.
2. https://www.pwabuilder.com 에 `https://seating-brown.vercel.app`를 넣고 **Start**를 누릅니다.
3. **Package For Stores → Android → Generate Package**를 누릅니다.
   - **Package ID**: `app.vercel.seating_brown.twa` (확정, 바꿀 수 없음)
   - **App name**: 교실 자리배치
   - **Signing key**: **Create new**를 고릅니다.
4. 받은 zip 파일 안에서 아래 파일들을 찾습니다.
   - `.aab` 파일: Play Console에 올리는 파일
   - `signing.keystore`와 `signing-key-info.txt`: 서명 열쇠. **꼭 안전한 곳에 백업**하세요. 잃어버리면 앱을 업데이트할 수 없습니다. GitHub에는 절대 올리지 마세요.
   - `assetlinks.json`: 주소창 없이 앱처럼 보이게 하는 파일. 이 파일을 받으면 앱 폴더의 `public/.well-known/assetlinks.json`에 넣어 다시 배포합니다.
5. Play Console의 **앱 서명** 메뉴에서 Google이 만든 **SHA-256 인증서 지문**도 `assetlinks.json`에 추가해야 합니다. 이 단계는 Claude에게 지문을 알려 주면 대신 넣어 드릴 수 있습니다.

## 4. 출시 순서 (개인 개발자 계정)

1. **Play Console 가입**: https://play.google.com/console 에서 등록비 25달러를 내고 본인 인증을 합니다(며칠 걸릴 수 있음).
2. **앱 만들기**를 누르고, 1~2번 내용을 입력합니다.
3. **비공개 테스트** 트랙에 `.aab`를 올리고 **테스터 12명 이상**을 초대합니다(Gmail 주소 필요).
   - 동료 선생님들께 부탁하면 좋습니다.
4. 테스터 12명이 **14일 연속** 참여한 뒤 **프로덕션 액세스 신청**을 합니다.
5. 심사(보통 며칠)를 통과하면 플레이스토어에 공개됩니다.
