# 🪑 교실 자리배치

선생님이 학생 자리를 랜덤으로 배치해 주는 웹앱입니다.
**같은 성별이 옆·앞뒤로 붙지 않게** 자동으로 배치하고, 결과를 인쇄하거나 엑셀로 저장할 수 있습니다.

React + Vite로 만들었습니다.

👉 **바로 사용하기: https://seating-brown.vercel.app**

## 실행하기

[Node.js](https://nodejs.org/) 18 이상이 필요합니다.

```bash
npm install      # 처음 한 번만
npm run dev      # 개발 서버 실행 → 브라우저에서 http://localhost:5173 열기
npm run build    # 배포용 파일을 dist/ 폴더에 만들기
```

## 주요 기능

- **자리 크기 설정**: 가로(분단) × 세로(줄)를 1~12까지 설정하고, 책상을 클릭해 빈자리로 바꿀 수 있습니다.
- **남녀 분리 랜덤 배치**: 같은 성별이 옆·앞뒤로 이웃하지 않도록 배치합니다. 인원 비율상 완벽한 분리가 어려우면 이웃한 쌍을 최소로 줄이고 안내합니다.
- **명단 입력**: 직접 입력하거나, 인원수만 정하면 `남1`, `여1`처럼 번호로 채웁니다.
- **명단 파일 불러오기**: 엑셀(`.xlsx` `.xls` `.csv`)이나 `.txt` 파일을 불러오거나 끌어다 놓을 수 있습니다.
  - "이름", "성별" 열이 있으면 남·여 명단으로 자동으로 나눕니다.
  - 성별 정보가 없는 파일은 남학생 또는 여학생 명단 중 어디에 넣을지 고릅니다.
- **인쇄**: 교실 배치도만 A4 가로 한 장에 인쇄합니다.
- **엑셀 저장**: 색이 칠해진 자리배치도 시트와 명단 시트가 담긴 `.xlsx` 파일로 저장합니다.
- **한글 / 영어** 화면 전환을 지원합니다.
- **앱 설치 (PWA)**: 휴대폰·PC 홈 화면에 설치할 수 있고, 한 번 열어 두면 인터넷 없이도 모든 기능이 동작합니다.

## 사용 방법

1. 가로·세로 칸 수를 정하고 **자리 설정**을 누릅니다.
2. 남학생·여학생 명단을 입력하거나 **📂 명단 파일 불러오기**로 파일을 엽니다.
3. **🎲 랜덤 배치**를 누릅니다.
4. 필요하면 **🖨️ 인쇄하기** 또는 **📊 엑셀로 저장**을 누릅니다.

### 명단 파일 형식

엑셀은 첫 줄에 `이름`, `성별` 머리글을 두면 됩니다. 번호 같은 다른 열이 있어도 됩니다.

| 번호 | 이름 | 성별 |
|---|---|---|
| 1 | 김민준 | 남 |
| 2 | 이서연 | 여 |

txt는 한 줄에 한 명씩 적습니다. 아래 형식을 모두 읽을 수 있습니다.

```
김민준 남
1 이서연 여
박도윤,남
최지우
```

성별은 `남/여`, `남자/여자`, `남학생/여학생`, `M/F`, `Boy/Girl`로 적을 수 있습니다.
`samples/` 폴더의 예시 파일로 바로 시험해 볼 수 있습니다.

등록 정보 초안과 단계별 방법은 [docs/store/스토어_등록정보.md](docs/store/스토어_등록정보.md)에 있습니다.

## GitHub Pages로 공개하기

빌드와 배포는 GitHub Actions가 자동으로 합니다([.github/workflows/deploy.yml](.github/workflows/deploy.yml)).

1. 이 저장소의 **Settings → Pages**로 이동합니다.
2. **Source**를 `GitHub Actions`로 선택합니다.
3. `main` 브랜치에 올리면 자동으로 빌드·배포됩니다. 진행 상황은 **Actions** 탭에서 볼 수 있습니다.
4. 배포가 끝나면 `https://<사용자이름>.github.io/<저장소이름>/` 주소로 접속할 수 있습니다.

## 참고

- 엑셀 읽기는 [SheetJS](https://sheetjs.com/), 엑셀 저장은 [ExcelJS](https://github.com/exceljs/exceljs)를 사용합니다. 두 라이브러리는 앱에 함께 묶여 있어 인터넷이 없어도 동작하고, 불러오기·저장 버튼을 처음 누를 때만 내려받습니다.
- 글꼴은 Google Fonts의 Jua, Gowun Dodum을 사용합니다. 인터넷이 없으면 맑은 고딕으로 표시됩니다.
- 입력한 명단은 브라우저 밖으로 전송되지 않습니다.
